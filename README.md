**1️⃣ What is the difference between var, let, and const?**

1. **var** – function scoped and can be redeclared.
2. **let** – block scoped and value can be changed.
3. **const** – block scoped and value cannot be reassigned.

**2️⃣ What is the spread operator (...)?**

1. It expands elements of an array or object.
2. Used to copy or merge arrays/objects easily.
3. Example: `let newArr = [...arr1, ...arr2]`.

**3️⃣ What is the difference between map(), filter(), and forEach()?**

1. **map()** – creates a new array by modifying each element.
2. **filter()** – creates a new array with elements that pass a condition.
3. **forEach()** – runs a function on each element but returns nothing.

**4️⃣ What is an arrow function?**

1. A short syntax to write functions in JavaScript.
2. Uses `=>` instead of the `function` keyword.
3. Example: `const add = (a,b) => a + b`.

**5️⃣ What are template literals?**

1. Used to write strings with variables easily.
2. Written using backticks `` ` ` `` instead of quotes.
3. Example: `` `Hello ${name}` ``.
