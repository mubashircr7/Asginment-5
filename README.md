1️⃣ Difference between var, let, and const

var old way variable, re-declare and change kora jay.

let variable change kora jay but same name e re-declare kora jay na.

const value change kora jay na (constant variable).

2️⃣ Spread Operator ...

... array/object er value gulo spread (copy) kore.

Easy way te array/object combine kora jay.

Example: [...arr1, ...arr2].

3️⃣ Difference between map(), filter(), forEach()

map() array theke new array return kore.

filter() condition diye kichu value select kore new array banay.

forEach() sudhu loop chalay, new array return kore na.

4️⃣ Arrow Function

Short way te function likhar modern JavaScript syntax.

function keyword lage na.

Example: const add = (a,b) => a+b.

5️⃣ Template Literals

Backtick ` ` diye string likha hoy.

${} diye variable easily use kora jay.

Multi-line string likha easy hoy.
